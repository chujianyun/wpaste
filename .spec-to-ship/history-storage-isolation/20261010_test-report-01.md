## 问题与改动

历史面板为空，但系统剪贴板有文字，记录未暂停，无搜索或类型过滤。旧实现采用 SwiftData 默认的 Application Support/default.store；现场该文件只包含另一套模型的数据表，没有 WPaste 历史表。默认路径在非沙箱应用间冲突。

- 持久库固定为 Application Support/WPaste/History.store，图片目录不变。
- 只读检查旧库是否包含 WPaste 三张业务表，使用 SQLite backup API 迁移，包含已提交的 WAL 数据；原库保留。
- 跳过其他应用的默认库；已有专属库不被迁移覆盖；内存测试库仍保持内存配置。
- 工程通过 XcodeGen 同步新增源码与测试文件。
