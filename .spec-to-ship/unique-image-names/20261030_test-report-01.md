# 图片粘贴文件名去重测试报告

日期：2026-10-30。源码基线：main `b0e1bbe`，开始时工作区干净；本次构建包含下述尚未提交的修复和测试。

## 改动范围

- 图片回填系统剪贴板时，同时提供一个有文件名的 PNG 文件 URL 和 PNG/TIFF 图片数据；这些格式属于同一个剪贴板项目。
- 文件名使用原始图片数据的完整 SHA-256：不同内容不同名，同一图片重复粘贴复用名称。导出存放在系统临时目录中的 WPaste/PastedImages，不依赖历史图片的存续。
- 将历史中可能以 .png 扩展名保存的 TIFF 数据转成真正的 PNG，保证导出文件内容和扩展名一致。
- 图片回填附带应用专用标记，监控器据此忽略自己的回填，避免文件 URL 或转码后指纹变化产生重复历史；不依赖用户是否启用敏感/临时内容过滤。
- 未修改界面、数据模型、签名配置或 project.yml。XcodeGen 在打包时重新运行，工程文件无差异。
