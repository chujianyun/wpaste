# WPaste 0.1.0

WPaste 首个公开安装包：原生 macOS 剪贴板历史、搜索、Pinboard 收藏与快捷粘贴。

## 下载

需要 **macOS 15.0 或更高版本**。

| 芯片 | 安装包 |
| --- | --- |
| Apple 芯片（M 系列） | `WPaste-0.1.0-macOS-arm64.dmg` |
| Intel | `WPaste-0.1.0-macOS-x86_64.dmg` |

打开 DMG，将 WPaste 拖到 Applications 后启动。需要自动粘贴时，在系统设置中授予辅助功能权限；未授权时仍可复制历史内容并手动粘贴。

## 功能

- 记录文字、链接、图片和文件，重复内容合并，按最近使用排序。
- 按内容、文件名和来源应用搜索，搜索框支持一键清空。
- 使用 Pinboard 分类收藏常用内容。
- 使用 ⌘⇧V 打开或收起历史面板，方向键选择、回车粘贴，支持 ⌘1–⌘9 快速粘贴与右键纯文本粘贴。
- 支持保留期限、暂停记录、忽略应用、敏感类型过滤和退出清理。
- 卡片显示来源应用图标；历史面板可直接打开设置，设置窗口采用宽屏布局并支持反复关闭、打开。
- README 提供安装说明、作者悟鸣的介绍、悟鸣AI 联系码和公众号二维码。

## 验证结果

- 完整测试：51 项通过、0 项失败、0 项跳过；含参数化用例共执行 53 次。
- 通用版及 arm64 / x86_64 Release archive 构建成功，构建日志无编译警告。
- 两个芯片版本均完成 Mach-O 架构、最低系统版本、Bundle ID 与固定开发证书签名校验。
- 通用 DMG 和两个芯片版本 DMG 均通过 `hdiutil verify`。
- 从本次构建的通用 archive 安装到 `/Applications/WPaste.app`，在 Apple 芯片 Mac 上启动并保持运行。
- 附件 `SHA256SUMS.txt` 提供两个 DMG 的 SHA-256 校验值。

## 已知限制与待验收项

- 使用 Apple Development 开发证书签名，尚无 Developer ID 分发签名和 Apple 公证。首次打开可能被 macOS 拦截；确认来源后，在「系统设置 → 隐私与安全性」中选择「仍要打开」。受组织管理的设备可能无法放行。
- Intel 版完成交叉编译、架构和签名校验；构建机未安装 Rosetta，尚未完成 Intel 实机启动和交互验收。
- 辅助功能权限需要用户手动授予；跨应用粘贴、多显示器、全屏、Spaces 和屏幕共享等交互仍需按[发布检查清单](https://github.com/chujianyun/wpaste/blob/main/docs/release-checklist.md)验收。
- 两张二维码使用作者提供的原图，需在微信中扫码确认当前可用性。
