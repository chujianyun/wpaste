# WPaste 0.1.1

基于最新代码发布 macOS Intel 和 Apple 芯片两个独立安装包，修复快捷粘贴的目标应用保持和辅助功能重复提示问题。

## 下载与安装

需要 **macOS 15.0 或更高版本**。在苹果菜单 →「关于本机」查看芯片类型。

| 芯片 | 下载 |
| --- | --- |
| Apple 芯片（M 系列） | [WPaste-0.1.1-macOS-arm64.dmg](https://github.com/chujianyun/wpaste/releases/download/v0.1.1/WPaste-0.1.1-macOS-arm64.dmg) |
| Intel | [WPaste-0.1.1-macOS-x86_64.dmg](https://github.com/chujianyun/wpaste/releases/download/v0.1.1/WPaste-0.1.1-macOS-x86_64.dmg) |

打开 DMG，将 `WPaste.app` 拖入 `Applications` 后启动。升级前先退出旧版，再替换「应用程序」中的 WPaste；现有本机历史和设置会保留。使用 ⌘⇧V 打开或收起历史面板，自动粘贴需要在系统设置中授予辅助功能权限。

下载两个 DMG 和 [SHA256SUMS.txt](https://raw.githubusercontent.com/chujianyun/wpaste/main/docs/releases/v0.1.1/SHA256SUMS.txt) 到同一目录，执行：

```bash
shasum -a 256 -c SHA256SUMS.txt
```

## 本次修复

- 打开历史面板后，持续持有原目标应用，避免系统释放应用包装对象导致自动粘贴无法回到原应用；真正退出的目标应用仍会安全降级为仅复制。
- 未获得辅助功能权限时，每次启动会话只请求一次权限，避免连续粘贴反复弹出提示；每次粘贴仍实时检查授权，授权后无需重启即可自动粘贴。

## 验证结果

- 完整测试：**54 项通过、0 项失败、0 项跳过**；含参数化用例共执行 **57 次**。
- 通用版、arm64 和 x86_64 均从本次源码生成 Release archive；测试和构建无编译警告。
- 两个分架构安装包均校验了 Mach-O 架构、版本 0.1.1（构建 2）、macOS 15.0 最低系统要求、Bundle ID 和固定开发证书签名。
- 通用 DMG 及两个分架构 DMG 均通过 `hdiutil verify`；挂载后确认两个发布包与对应 archive 内容一致，并包含 Applications 快捷链接。
- 从本次通用 archive 安装到 `/Applications/WPaste.app`，已停止旧进程并在 Apple 芯片 Mac 上重新启动，进程持续运行。

## 已知限制与待验收项

- 当前使用 **Apple Development 开发证书签名，尚无 Developer ID 分发签名及 Apple 公证**。首次打开可能被 macOS 拦截；确认来源后，在「系统设置 → 隐私与安全性」中选择「仍要打开」。受组织管理的设备可能无法放行。
- Intel 版完成交叉编译、架构、签名与安装包校验；构建机未安装 Rosetta，**Intel 实机启动和交互验收尚未完成**。
- 辅助功能权限需要用户手动授予；跨应用粘贴、多显示器、全屏、Spaces 和屏幕共享等交互仍需按[发布检查清单](https://github.com/chujianyun/wpaste/blob/v0.1.1/docs/release-checklist.md)验收。
