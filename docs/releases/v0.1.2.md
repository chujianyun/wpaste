# WPaste 0.1.2

需要 **macOS 15.0 或更高版本**。

## 下载与安装

| 芯片 | 下载 |
| --- | --- |
| Apple 芯片（M 系列） | [WPaste-0.1.2-macOS-arm64.dmg](https://github.com/chujianyun/wpaste/releases/download/v0.1.2/WPaste-0.1.2-macOS-arm64.dmg) |
| Intel | [WPaste-0.1.2-macOS-x86_64.dmg](https://github.com/chujianyun/wpaste/releases/download/v0.1.2/WPaste-0.1.2-macOS-x86_64.dmg) |

打开 DMG，将 WPaste.app 拖入 Applications。升级前先退出旧版本，本机历史和设置会保留。使用 ⌘⇧V 打开历史面板；自动粘贴需要辅助功能权限。

将两个 DMG 和 [SHA256SUMS.txt](https://github.com/chujianyun/wpaste/releases/download/v0.1.2/SHA256SUMS.txt) 下载到同一目录，执行 `shasum -a 256 -c SHA256SUMS.txt` 校验。

## 本次更新

- 新增历史内容类型筛选，改进搜索输入和清空按钮。
- 访达复制的图片文件支持缩略图；单张图片和纯图片文件组可出现在图片筛选结果中，并支持文件名搜索，仍保留原有文件复制语义。
- 视频文件卡片显示首帧预览；无法读取时保留图标回退。
- 没有收藏分类时隐藏空菜单，收藏成功后显示提示。

## 验证结果

- 60 项测试通过、0 失败、0 跳过；参数化后共执行 64 次。
- 通用版、arm64、x86_64 Release archive 均从本次源码生成，版本为 0.1.2（构建 3）。无编译警告。
- 通用 DMG 和两个发布 DMG 均通过 `hdiutil verify`。两个发布包挂载后，应用内容与对应 archive 一致；架构、签名、最低系统版本及 Applications 链接检查通过。
- 已安装到 `/Applications/WPaste.app`，确认旧进程退出、新进程持续运行；新版本满足旧版本签名身份要求，entitlements 未变。

## 已知限制与待验收

- 使用既有 Apple Development 开发证书，**尚未完成 Developer ID 分发签名及 Apple 公证**。首次打开可能被 macOS 拦截；确认来源后可在系统设置的隐私与安全性页面处理。受组织管理的设备可能无法放行。
- Intel 已完成交叉编译和产物检查，尚未完成 Intel 实机启动及交互验收。
- 本次界面自动化读取连续超时，图片筛选的已安装版本界面验收及已有辅助功能授权的实际粘贴验证仍待人工完成，不能仅凭进程运行认定通过。
- Xcode 测试结果记录一条内部线程优先级运行时警告：高优先级线程等待默认优先级线程，来源为 FeatureStoreTests；未导致测试失败。尚未定位具体等待点，不认定已消除。
